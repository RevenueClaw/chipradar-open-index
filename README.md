# ChipRadar Open Index

Public weekly data snapshots of the **ChipRadar Edge AI & SBC Price Index** — vendor-tracked pricing across SBCs, Jetson modules and mini PCs, with cited on-board LLM benchmarks.

- Live page: https://chipradar.io/market-index/latest
- RSS feed: https://chipradar.io/market-index/feed.xml
- Full machine-readable snapshots: `weekly-index/` (JSON + Markdown, one file per ISO week + `latest.*`)
- REST API + tiers: `openapi-chipradar.yaml` (Free / Indie $12 / Pro $49 / Enterprise $199)

All prices are retailer/vendor prices. We never track, store, or display Amazon pricing. Figures are generated from real DB rows — no invented numbers.

Data reuse requires attribution to ChipRadar (chipradar.io). Provided as-is with no warranty.
